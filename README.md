# leanPrice

A lightweight, self-hosted product discovery, price comparison and sale-alert application for South African retailers, designed for Raspberry Pi ARM64.

**Status:** product definition and architecture planning. No application implementation has been released.

**Non-negotiable:** the complete Pi-hosted runtime, including searches, scheduled scraping and notifications, must remain within a **500 MB RAM ceiling**. External search/browser services, if used, are not included in the Pi runtime and must remain optional and explicitly disclosed.

Documentation will be managed through reviewed pull requests: product specification first, technical plan only after product specification merges into `main`.

Development and validation occur locally; this repository does not require GitHub Actions.
