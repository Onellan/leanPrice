# deliver-slice

**Trigger:** slice LP-P*-B*-S* delegated for end-to-end delivery.

Read approved slice, linked acceptance IDs, dependencies and current candidate SHA. Implement one cohesive change; targeted test evidence and failure cases; commit with traceable scope; invoke independent code review and acceptance. If findings appear, return them to implementer and retest exact updated SHA.

Do not expand to adjacent backlog work or create unsupported retailer assumptions. Do not bypass or dilute the hard Pi memory ceiling or source compliance to make a slice pass. If slice depends on unfinished work or unassessed retailer extraction, stop with BLOCKED and a concrete reason. Batch-wide independent certification comes later; delivering a slice does not automatically certify a batch/release.
