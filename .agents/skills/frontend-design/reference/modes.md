# Surface Modes

Load this when the surface's mode materially affects design decisions.

## Persuade

The visitor should decide, believe, sign up, contact, purchase, subscribe, or take another intentional action.

Priority:

```text
attention → comprehension → credibility → desire → action
```

Use stronger visual identity when it serves the brief. Typography, imagery, composition, and motion may carry persuasion. Avoid generic SaaS/hero patterns unless they genuinely fit the subject.

## Operate

The user is performing a task: application UI, dashboards, admin, settings, tools, editors, workflow systems.

Priority:

```text
orientation → scanability → comprehension → action → feedback → continued flow
```

Familiarity is often a feature. Identity should usually live in precision, typography, spacing, density, state treatment, iconography, and a few characteristic details rather than reinvented controls.

Operate defaults:

- consistency over surprise;
- restrained colour on inactive states;
- familiar navigation and control affordances;
- deliberate information density where the work requires it;
- clear states: default, hover, focus, active, disabled, loading, error;
- short functional motion, not page-load choreography;
- tables stay tables when the task is tabular;
- modals are not the first answer to every secondary task.

The failure mode is not visual quietness; it is strangeness without purpose.

## Read

The user is trying to understand information: docs, articles, guides, reports, help, changelogs.

Priority:

```text
wayfinding → readability → comprehension → retention
```

Typography, measure, heading hierarchy, navigation, and content structure dominate. Distinctiveness should not compete with reading.

## Experience

The work/artifact itself leads: portfolios, galleries, immersive editorial or showcase surfaces.

Priority:

```text
artifact → atmosphere → exploration → memorable interaction
```

The interface may recede or become expressive depending on the brief. Strong visual/world-building choices are legitimate when they reinforce the artifact.

## Distinctiveness calibration

```text
Persuade   high opportunity
Experience high opportunity
Read       moderate opportunity
Operate    low-to-moderate opportunity
```

This is not a quality ranking. It is a reminder that novelty has different costs by mode.

## Mixed products

Classify the surface, not the brand or application as a whole. A software product may have:

- a Persuade landing page;
- an Operate authenticated app;
- a Read documentation centre;
- an Experience showcase.

Do not drag the design grammar of one mode into another without a reason.
